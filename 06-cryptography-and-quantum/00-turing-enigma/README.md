# Enigma and the Bombe

The Enigma machine encrypts by composing rotor, reflector, and plugboard permutations. The Bombe searched machine settings by exploiting known plaintext and contradictions.

## Open

- [enigma.ipynb](enigma.ipynb)

## What To Watch

- Rotor position is machine state.
- Encryption and decryption use the same machine settings.
- The plugboard greatly enlarges the key space.
- A crib turns a search problem into a set of constraints.
