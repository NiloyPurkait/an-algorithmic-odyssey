# Antikythera Mechanism

The Antikythera Mechanism is useful here because it computes without software in the usual sense. Gear teeth encode ratios, and turning the crank advances a deterministic astronomical model.

## Open

- [antikythera-mechanism.ipynb](antikythera-mechanism.ipynb)

## What To Watch

- Gear trains multiply angular motion by rational numbers.
- Calendar cycles become modular arithmetic on dials.
- The engineering problem is approximation: integer teeth must represent messy astronomical periods.
