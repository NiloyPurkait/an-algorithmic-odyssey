# Markov Chains

Markov chains model systems whose next state depends only on the current state. A transition matrix moves probability mass through the state space, and repeated steps reveal long-run behavior. Uncertainty becomes dynamic rather than a one-time calculation.

## Open

- [markov-chains.ipynb](markov-chains.ipynb)

## What To Watch

- A transition matrix stores probabilities from one state to the next.
- Rows of a row-stochastic matrix sum to 1.
- Multiplying a distribution by the matrix advances the model one step.
- A stationary distribution stays unchanged by the transition matrix.
