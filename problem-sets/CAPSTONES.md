# Capstone Menu

Choose one capstone. Each option should include a notebook, written report, visual trace or interactive animation, and a short demo.

## 1. Algorithm Animation Studio

Build a visual player for three algorithms from different modules.

Required:

- shared trace format
- play/pause/step/reset
- visible invariant
- operation counter
- one failure-mode toggle

## 2. City Systems Lab

Model a small city or service area with roads, delivery routes, bottlenecks, and demand.

Required:

- Voronoi service regions for depots, towers, hospitals, or shelters
- shortest path
- minimum spanning structure
- max flow or capacity analysis
- visual comparison of two planning decisions

## 3. Generated World

Create a small world, social simulation, or artificial-life system using terrain generation, local interaction, movement rules, or selected morphology.

Required:

- Perlin or related noise, or Biomorph-style genome-to-phenotype generation
- grid-based local dynamics, social-agent movement rules, swarm rules, or artificial selection
- at least two parameter regimes
- written explanation of emergent behavior

## 4. Data Science Mini-Lab

Analyze a small network, dataset, or signal.

Required:

- PageRank or Markov model
- k-means or gradient descent
- exact/estimated/optimized distinction
- plots or diagrams that explain the result

## 5. Search Under Pressure

Compare Minimax, MCTS, and a metaheuristic on a game or planning problem.

Required:

- common problem representation
- visual search traces
- performance comparison under fixed budget
- explanation of when each method fails

## 6. Cryptography and Quantum Threat Model

Build a tiny RSA demonstration and connect it to period finding.

Required:

- key generation trace
- modular exponentiation trace
- period-finding table for a small number
- explanation of why deployed RSA needs large keys and padding, and why Shor's algorithm matters only with scalable fault-tolerant quantum hardware
