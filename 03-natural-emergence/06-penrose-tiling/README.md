# Penrose Tiling

Penrose tilings are non-periodic tilings with long-range order. The notebook uses replacement rules to build structure that never settles into a repeating wallpaper pattern.

## Open

- [tiling.ipynb](tiling.ipynb)

## What To Watch

- Deflation replaces tiles with smaller tiles.
- Matching rules constrain which edges may touch.
- The golden ratio appears in the geometry and scaling.
- Local constraints can force global non-periodicity.
