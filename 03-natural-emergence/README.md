# Module 3: Emergence, Chaos, & Natural Simulations

Small local rules can create large, surprising structure. This module uses visual systems to show how social patterns, motion, morphology, terrain, and geometry can emerge from repeated mathematical rules.

## Field

Artificial life, sociology, evolutionary biology, mathematical biology, procedural generation, geometry, and complex systems.

## Learning Arc

1. [Game of Life](00-game-of-life/game-of-life.ipynb) starts with a grid where neighbor rules create moving structures.
2. [Schelling's Model of Segregation](01-schelling-segregation/schelling-segregation.ipynb) shows how mild local preferences can amplify into macro-level clustering.
3. [Boids](02-boids/boids.ipynb) turns local vector rules into flocking and swarm behavior.
4. [Dawkins' Biomorphs](03-biomorphs/biomorphs.ipynb) shows cumulative artificial selection over a compact genome.
5. [Turing Patterns](04-turing-patterns/turing-patterns.ipynb) turns local interaction into reaction-diffusion patterns.
6. [Perlin Noise](05-perlin-noise/perlin-noise.ipynb) generates smooth pseudo-random terrain for graphics and worlds.
7. [Penrose Tiling](06-penrose-tiling/tiling.ipynb) shifts from pixels to recursive geometry and non-repeating order.

## Why This Module Matters

After graph rigor, students get visual feedback. The lesson is precise: complexity does not always require complex rules. It can appear in social grids, fields, agent motion, selected lineages, or geometry.

## Checkpoint

Create a small generated world, social grid, or organism set: use Perlin noise for terrain, Schelling agents for social pattern, or Biomorph genes for form; then describe how one parameter change affects the visible pattern.
