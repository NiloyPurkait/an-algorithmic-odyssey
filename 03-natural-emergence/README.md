# Module 3: Emergence, Chaos, & Natural Simulations

Small local rules can create large, surprising structure. This module uses visual systems to show how patterns, motion, terrain, and geometry can emerge from repeated mathematical rules.

## Field

Artificial life, mathematical biology, procedural generation, geometry, and complex systems.

## Learning Arc

1. [Game of Life](00-game-of-life/game-of-life.ipynb) starts with a grid where neighbor rules create moving structures.
2. [Boids](01-boids/boids.ipynb) turns local vector rules into flocking and swarm behavior.
3. [Turing Patterns](02-turing-patterns/turing-patterns.ipynb) turns local interaction into reaction-diffusion patterns.
4. [Perlin Noise](03-perlin-noise/perlin-noise.ipynb) generates smooth pseudo-random terrain for graphics and worlds.
5. [Penrose Tiling](04-penrose-tiling/tiling.ipynb) shifts from pixels to recursive geometry and non-repeating order.

## Why This Module Matters

After graph rigor, students get visual feedback. The lesson is precise: complexity does not always require complex rules. It can appear in grids, fields, agent motion, or geometry.

## Checkpoint

Create a small generated world: use Perlin noise for terrain, add a grid-based or agent-based local rule, and describe how one parameter change affects the visible pattern.
