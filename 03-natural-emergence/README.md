# Module 3: Emergence, Chaos, & Natural Simulations

Small local rules can create large, surprising structure. This module uses visual systems to show how patterns, motion, morphology, terrain, and geometry can emerge from repeated mathematical rules.

## Field

Artificial life, evolutionary biology, mathematical biology, procedural generation, geometry, and complex systems.

## Learning Arc

1. [Game of Life](00-game-of-life/game-of-life.ipynb) starts with a grid where neighbor rules create moving structures.
2. [Boids](01-boids/boids.ipynb) turns local vector rules into flocking and swarm behavior.
3. [Dawkins' Biomorphs](02-biomorphs/biomorphs.ipynb) shows cumulative artificial selection over a compact genome.
4. [Turing Patterns](03-turing-patterns/turing-patterns.ipynb) turns local interaction into reaction-diffusion patterns.
5. [Perlin Noise](04-perlin-noise/perlin-noise.ipynb) generates smooth pseudo-random terrain for graphics and worlds.
6. [Penrose Tiling](05-penrose-tiling/tiling.ipynb) shifts from pixels to recursive geometry and non-repeating order.

## Why This Module Matters

After graph rigor, students get visual feedback. The lesson is precise: complexity does not always require complex rules. It can appear in grids, fields, agent motion, selected lineages, or geometry.

## Checkpoint

Create a small generated world or organism set: use Perlin noise for terrain or Biomorph genes for form, add a local rule or selection rule, and describe how one parameter change affects the visible pattern.
