# Turing Patterns

Turing patterns come from reaction-diffusion systems: chemicals or fields react locally while diffusion spreads them through space.

## Open

- [turing-patterns.ipynb](turing-patterns.ipynb)

## What To Watch

- Reaction changes values at a location.
- Diffusion moves values between neighboring locations.
- A nearly uniform field can become unstable and form stripes or spots.
- Numerical choices such as timestep and boundary behavior affect the picture.
