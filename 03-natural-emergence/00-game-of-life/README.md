# Conway's Game of Life

The Game of Life is a two-state cellular automaton. Every cell follows the same neighbor-count rule, and the grid produces still lifes, oscillators, gliders, and larger constructions.

## Open

- [game-of-life.ipynb](game-of-life.ipynb)

## What To Watch

- All cells update from the previous generation, not from partially updated neighbors.
- Local rules can create moving structures.
- Initial conditions matter as much as the rule.
- Pattern names are descriptive categories: still life, oscillator, spaceship, growth pattern.
